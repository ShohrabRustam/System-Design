Problem : Find a user is online/offline?

Requirements
    Track when a user comes online (login, app open, websocket connect, etc.).

    Track when a user goes offline (logout, app close, websocket disconnect, timeout).

    Provide an API → GET /user/{id}/status → returns ONLINE or OFFLINE.

    Support real-time updates (e.g., friends list showing live status).


Components

    Client Applications (Mobile/Web/Desktop)

    Sends heartbeat / connect & disconnect events.

    Uses WebSockets or long polling to maintain live connection.

    Gateway / Load Balancer

    Routes user connections to backend services.

Presence Service

    Core microservice that handles online/offline events.

    Updates user’s status in a fast in-memory store (Redis).
    Key: userId  
    Value: {status: ONLINE, lastSeen: timestamp}  
    TTL: e.g., 1 min → auto-expiry if no heartbeat
