Some New Words to explore or learn
1.Load Balancer: 
A load balancer distributes network traffic across 
multiple servers to optimize resource utilization, 
improve application performance, and ensure high availability. 
It acts as a single point of contact for clients, 
directing traffic to the most available and responsive servers


2.Cassandra: 
Apache Cassandra is an open-source, distributed NoSQL database built 
for managing massive amounts of data with high availability and 
fault tolerance. 
It features a decentralized, peer-to-peer architecture where data is 
partitioned and replicated across nodes in a ring formation, 
eliminating single points of failure and providing continuous service 
and linear scalability across multiple data centers and cloud environments. 
Cassandra is known for its fast write performance and tunable consistency,
making it a popular choice for applications requiring immense scale 
and reliability.  

    Key Characteristics
        Distributed and Decentralized: Cassandra operates across a network of servers (nodes) in a cluster, where each node is equally important, and no single master node is relied upon. 
        High Availability: The decentralized architecture and data replication across multiple nodes ensure that the database remains available even if individual nodes or entire data centers fail. 
        Scalability: It is designed to scale linearly, meaning you can increase its storage and processing capacity by simply adding more nodes to the cluster. 
        NoSQL Database: As a NoSQL database, it stores data in a flexible, schema-optional format, which is different from traditional relational databases with fixed schemas. 
        Fault Tolerance: Data is automatically partitioned and replicated, allowing for fault tolerance, where data can still be accessed and processed if some nodes are unavailable. 
        Cross-Data Center Distribution: Cassandra can spread data across multiple data centers, making it resilient to regional outages.
